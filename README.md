# Muhammed Hanin Fuaad — Portfolio
Responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — content and page structure
- `style.css` — editorial styling, responsive layout and animation
- `script.js` — navigation, scroll reveals, progress indicator and pointer interactions
- `assets/hanin-portrait.jpg` — supplied portrait used in the intro and hero

## Run locally
Open `index.html` in a browser or use Live Server in VS Code.

## Publish with GitHub Pages
Push the contents of this folder to a GitHub repository, then open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.


The Certificate Verification System and CSQueryConnect are presented as project-detail sections because their GitHub repositories are private. Their source code is not linked publicly.


The opening section starts in a dark theme and blends into the warm light theme as you scroll toward the About section. Section reveals are triggered by scrolling; there is no timed intro overlay.

Opening animation update: a soft sage-grey hero (not a dark theme) with oversized HANIN typography that lifts and fades as the visitor scrolls into the warm ivory About section. The transition is scroll-led, not timed.
